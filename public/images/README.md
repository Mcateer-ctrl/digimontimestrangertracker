# Digimon Images

Place your Digimon images in this folder using the following naming convention:

## Naming Convention

The filename should match the Digimon name with spaces replaced by underscores:

- `Apollomon.png`
- `Alphamon.png`
- `UlforceVeedramon.png`
- `WarGreymon.png`
- `MetalGarurumon.png`
- `Cherubimon_(Black).png` (for names with parentheses)
- etc.

## Supported Formats

- `.png` (recommended - supports transparency)
- `.jpg` / `.jpeg`
- `.webp`

## Image Recommendations

- **Size**: 400x400px to 600x600px
- **Format**: PNG with transparent background looks best
- **Optimization**: Compress images to keep file sizes under 100KB each

## How Images Are Used

Images are displayed at the top of each Digimon card:
- Automatically centered and scaled to fit
- Gracefully hidden if image doesn't exist
- Background gradient applied for visual polish

If an image is missing, the card will still display properly with just the name, attribute, and link.
